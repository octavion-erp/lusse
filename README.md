# LUSSÉ — 100% Human Hair Extensions

Official website for **LUSSÉ**, a Dubai atelier for 100% Remy human hair extensions.

- **Live site:** https://lussehair.com
- **Instagram:** [@lussehaircom](https://www.instagram.com/lussehaircom/)
- **WhatsApp:** [+971 54 200 5442](https://wa.me/971542005442)

## Stack

- **Frontend:** Static HTML/CSS/JS (single-page, no build step)
- **Hosting:** Vercel
- **Analytics:** Vercel Analytics + Speed Insights
- **DNS:** Cloudflare
- **Languages:** English · Arabic (RTL) · Russian

## Structure

```
├── index.html          # the whole site (single-page)
├── videos/             # gallery videos
├── og.jpg              # social share image
├── robots.txt
├── sitemap.xml
└── vercel.json
```

## Deploy

Deployed automatically on every push to `main` via Vercel Git integration
(or manually with `vercel deploy --prod --yes`).
